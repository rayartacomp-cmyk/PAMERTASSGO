# 🏥 PAMERTASS Website

Website resmi Palang Merah Remaja SMAN 17 Surabaya dengan desain mirip JKT48.com

## 🚀 Fitur Utama

### 1. **Sistem Anggota**
- Registrasi anggota baru
- Login anggota
- Dashboard My Page
- QR Code personal untuk absensi
- Edit profil dan ganti password

### 2. **Sistem Admin**
- Login admin terpisah
- Dashboard admin lengkap
- Scan QR Code untuk absensi
- Kelola data anggota
- Kelola jadwal kegiatan
- Manajemen obat dan pasien
- Generate laporan

### 3. **Fitur Khusus**
- **QR Code Absensi** - Presensi digital tanpa kertas
- **Manajemen Obat** - Stok real-time dengan alert
- **Data Pasien** - Riwayat penanganan lengkap
- **Jadwal Dinamis** - Bisa diedit admin
- **Responsive Design** - Mobile & desktop friendly
